# 🗄️ Database Persistence Guide

## ❗ Проблема

**При кожному деплої на Render:**
- Бот перезапускається
- `init_db()` видаляє ВСІ таблиці
- **Всі дані втрачаються!**

---

## ✅ Рішення

### Зміни в `db.py`:

**Було:**
```python
cursor.execute("DROP TABLE IF EXISTS user_inventory CASCADE")
cursor.execute("DROP TABLE IF EXISTS shop_items CASCADE")
# ... видалення всіх таблиць
```

**Стало:**
```python
# DROP TABLE закомічено - зберігаємо дані!
# cursor.execute("DROP TABLE IF EXISTS user_inventory CASCADE")
# cursor.execute("DROP TABLE IF EXISTS shop_items CASCADE")
```

---

## 🛠️ Команди для управління БД

### `/dbstatus` - Перевірити статус

**Використання:**
```
/dbstatus
```

**Результат:**
```
📊 Статус бази даних:

Хряки: 15 записів
Баланси: 25 записів
Гільдії: 3 записів
Крипто-транзакції: 42 записів
```

### `/resetdb CONFIRM` - Скинути БД

**УВАГА:** Це видалить ВСІ дані!

**Використання:**
```
/resetdb          # Покаже попередження
/resetdb CONFIRM  # Скине БД
```

## 🚀 Деплой на Render

### Тепер при деплої:

1. ✅ Бот запускається
2. ✅ Таблиці НЕ видаляються
3. ✅ **Всі дані зберігаються**
4. ✅ Гравці не втрачають прогрес

### Якщо потрібно змінити структуру:

1. **Відкрий `db.py`**
2. **Розкоментуй DROP TABLE:**
   ```python
   cursor.execute("DROP TABLE IF EXISTS user_inventory CASCADE")
   ```
3. **Задеплой**
4. **Закоментуй назад** (щоб зберегти нові дані)

## 🎯 Гільдії - як працюють

### Команди:

| Команда | Опис |
|---------|------|
| `/createguild <назва> [опис]` | Створити гільдію (100 монет) |
| `/guild [назва]` | Інформація про гільдію |
| `/guildjoin <назва>` | Приєднатися до гільдії |
| `/guildleave` | Вийти з гільдії |
| `/guildtop` | Рейтинг гільдій |
| `/contribute <сума>` | Внесок до гільдії |
| `/transferguild <user_id>` | Передати володіння |
| `/deleteguild` | Видалити гільдію |

### Механіка:

1. **Створення:** 100 монет
2. **Володіння:** Один власник
3. **Учасники:** Необмежено
4. **Внески:** Записуються в БД
5. **Рейтинг:** За сумою внесків

### Збереження:

- ✅ Гільдії зберігаються між деплоями
- ✅ Учасники не втрачаються
- ✅ Внески залишаються
